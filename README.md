# Drift Shell 0.1.0-dev

Экспериментальная оболочка и Wayland-композитор для Arch Linux.

> Проект находится в разработке. Полное соответствие ТЗ, установка на реальной
> Arch Linux и безопасность полноценного сеанса пока не подтверждены.
> Текущее состояние описано в [STATUS-RU.md](STATUS-RU.md).

## Установка на Arch Linux

Запускайте команды от обычного пользователя:

```bash
git clone https://github.com/Venhel7-ai/drift-shell.git
cd drift-shell
bash install.sh --start
```

Установщик обновит системные пакеты, установит зависимости, соберёт проект через
`makepkg`, установит пакет `drift-shell` и запустит экспериментальный сеанс.
Потребуются интернет, подтверждения `sudo`/`pacman` и время на компиляцию.

После установки проект можно запускать командой:

```bash
drift-shell-session
```

Подробная документация: [README-RU.md](README-RU.md).
