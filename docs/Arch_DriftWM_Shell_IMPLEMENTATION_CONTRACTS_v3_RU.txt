V3 IMPLEMENTATION AMENDMENTS
======================================================================

1. PROFILE SYSTEM

Profile object:
id
name
inherits
visualOverrides
behaviorOverrides

Built-in:
work
reference
focus-presentation
minimal
showcase

Profile switching must be transactional and must not rewrite user's per-zone layout tree.

2. RIGHT PANEL STATE MACHINE

States:
Hidden
ShowingPeek
Peek
HidingPeek
PreparingPin
Pinned
Unpinning

Peek->Pinned:
reserve target first;
layout begins shrink;
panel remains visible;
when layout reaches safe progress, state Pinned.

Pinned->Peek:
release reserve;
layout expands;
panel remains overlay.

Any transition is reversible.

3. DOCK STATE MACHINE

Hidden
Revealing
VisibleOverlay
VisiblePinned
Hiding

WORK startup = Hidden.
Pointer edge optional.
Bind always works.

4. MATERIAL TOKENS

Every Surface component has:
materialRole = App | Shell | Overlay

It may not set arbitrary blur directly unless expert override enabled.
Default values come from Theme.

5. GRAPH RENDER POLICY

metricsGraphPolicy:
Off
OnHover
ExpandedOnly
Always

Sampling continues at backend cadence independent of rendering.
Hidden graphs do not request repaint.

6. SETTINGS LEVEL

Property metadata contains:
uiLevel = Basic | Advanced | Expert

Search ignores uiLevel filter when exact result is found.

7. DESIGN CONTAINERS

Every movable UI component has:
containerId
order
alignment
stretch
min/max
visibility

absoluteX/Y only valid if layoutMode=Absolute and expertMode=true.

8. LOCK/GREETER THEMING

Lock and Greeter import same generated token snapshot but do not import arbitrary third-party QML widgets.

9. QUICK WORKSPACE SWITCHER

VisibleSlots algorithm:
include active
include nearest previous/next
include occupied quickSlots until maxVisible=5
if more -> overflow.

Keyboard slots 1..9 remain independent from visible slots.

10. TITLEBAR POLICY

Tiled:
compact 29 px.
Floating:
29–34 px configurable.
Reference:
legacy 34 px.

11. WORK SAFE AREA

Default:
TopBar reserves top.
RightPanel Hidden/Peek does not reserve.
Dock overlay does not reserve.
Pinned Right/Dock reserve only when explicitly configured.

12. SEMANTIC COLOR TEST

Automated UI linter should detect use of SUCCESS/ERROR tokens.
Allowed semantic roles must be declared in component metadata.
A CPU graph declaring genericMetric cannot bind SUCCESS color.

13. ANIMATION PRESETS

work-fast
reference-smooth
reduced-motion

No component hard-codes duration if matching preset token exists.

14. STARFIELD PERFORMANCE

Stars rendered as one batched node/shader where possible.
No one-QML-object-per-star design at production scale.
Static Anchored scene should not continuously repaint.

15. WINDOW MATERIAL

Compositor must not force blur behind every application unless profile enables it.
Opaque-ish application surfaces are preferred.

16. REFERENCE GOLDENS

All existing historic reference screenshots are tested under profile=reference.
New ergonomic golden screenshots are tested under profile=work.
These are separate baselines and must not be mixed.

======================================================================
8. ZONE SNAP ALGORITHM
======================================================================

Candidate if:
screenSpaceDistance < snapThreshold
AND zoom delta within tolerance.

Default:
snapThreshold = 0.35 viewport diagonal.
zoomTolerance ≈12%.
hysteresis ≈10%.

Score:
normalizedDistance + zoomPenalty.
Lowest score wins.
