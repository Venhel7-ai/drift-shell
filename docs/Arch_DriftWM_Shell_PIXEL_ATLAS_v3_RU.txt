21. PIXEL QA PROCEDURE
======================================================================

1. Run Preview 1672×941 exactly.
2. Scale 100%.
3. Same pinned Inter/JetBrains Mono versions.
4. Deterministic stars.
5. Frozen time/date/mock data.
6. Freeze animation at required state.
7. Render PNG.
8. Produce pixel-diff and perceptual-diff.
9. Geometry-critical difference >2 px = fail.
10. Radius difference >1 px = fail.
11. Border visually >1 logical px = fail.
12. Wrong semantic green/red = fail.
13. Blue/yellow/purple shell accent = fail.
14. English shell-owned production string = fail.
15. Lock/login instructional hint = fail.
16. System landscape wallpaper = fail.
17. RightPanel visible pixels after hidden state = fail.
18. Dock visible pixels after hidden state = fail.

Blur/font antialiasing compare perceptually, not byte-for-byte.
