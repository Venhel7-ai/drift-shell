======================================================================
V3 — НОРМАТИВНАЯ РЕДАКЦИЯ ДЛЯ ЕЖЕДНЕВНОЙ РАБОТЫ
======================================================================

СТАТУС V3
Эта редакция исправляет главный недостаток ранних референсов: они были оптимизированы прежде всего под красивый статичный скриншот, а не под многочасовую работу программиста, администратора серверов и пользователя tiling-WM.

V3 НЕ отменяет возможность воспроизвести исходные изображения. Вместо этого вводятся два чётко разделённых режима оформления:

1. WORK — основной production-профиль. Он обязан быть максимально спокойным, быстрым и не занимать экран без необходимости.
2. REFERENCE / SHOWCASE — профиль, который максимально близко воспроизводит исходные изображения: закреплённая правая колонка, видимый dock, широкая строка поиска и более выраженное стекло.

Если пользователь не выбрал профиль явно, запускается WORK.

При конфликте между старым текстом V1/V2 и этим блоком V3 применяется V3.

======================================================================
V3.1. ГЛАВНЫЙ ПРИНЦИП
======================================================================

Оболочка должна исчезать, когда она не нужна.

Функциональность не должна доказывать своё существование постоянным присутствием на экране. Большая часть возможностей вызывается по бинду, hover-edge, search или popover.

Нормальный рабочий экран должен визуально состоять только из:
- чёрного фона со слабыми звёздами;
- компактной верхней панели;
- рабочих окон;
- кратковременных уведомлений при необходимости.

Правой колонке, dock, notification center, popover, large search, design guides и дополнительным виджетам запрещено быть постоянно видимыми в WORK, если пользователь их явно не закрепил.

- online;
- connected;
- successful;
- completed;

- offline;
- failed;

Если статус невозможно однозначно отнести к success/error, он отображается белым с нужной opacity.

Вместо бинарного show/hide вводятся:

HIDDEN:
- surface полностью за правой границей;
- input region пуст;

- видимых 1–8 px hotzone по умолчанию НЕТ, если управление bind-only;

PEEK:
- панель выезжает поверх текущих окон;
- Safe Area НЕ меняется;
- окна НЕ перераскладываются;
- panel z-level выше application windows;
- закрывается по повторному bind, Escape, click outside или timeout, если autoClose=true.

PINNED:
- панель резервирует ширину;
- tiling пересчитывается;
- panel остаётся до явного unpin.

Recommended binds:
Super+R -> Hidden <-> Peek
Super+Shift+R -> Pinned <-> Hidden/previous state

Peek width:
290 px reference.
Pinned width:
290 px reference.

Peek нельзя автоматически превращать в Pinned.

В WORK default Hidden.
В REFERENCE default Pinned.

Idle TopBar search — маленький trigger.
Полная панель существует только после вызова.

Open width:
620 px reference.
max height:
500 px.

Первые результаты:
Apps / Windows / Zones / Commands.

Secondary providers:
Settings / Files / Servers / Browser bookmarks.

Search UI должен визуально быть самым выраженным glass overlay, потому что он временный.

======================================================================
V3.17. LOCK SCREEN — ЕЩЁ МИНИМАЛИСТИЧНЕЕ
======================================================================

WORK/default lock содержит:
- Arch identity top-left;
- compact status pill top-right;
- большие часы;
- дату;
- avatar;
- username.

Default:
quote=false.
notifications content=false.
password box hidden пока пользователь не начал ввод.
никаких подсказок.
никаких кнопок в центре.
никакой большой card вокруг пользователя.

После первого печатного символа:
- clock translateY -18 px;
- scale 1 -> 0.94;
- date opacity 1 -> 0.55;
- password line/pill появляется под username.

Password control:
width 300 px.
height 40.
background почти прозрачный Level B.
border idle 0.12.
focus 0.28 white.

Wrong:
короткий red border + shake.
Не выводить большой текст ошибки, если PAM не требует конкретное сообщение.
Можно показать «Неверный пароль» маленьким 11 px text на 1.5 s, если user setting enabled; default off.

======================================================================

Ранее login помещался в крупную центральную glass-card. В WORK V3 card удаляется.

Центральная вертикальная группа:
avatar 78 px;
username;
password pill;
optional session selector только при >=2 session;
login action implicit Enter, отдельная кнопка «Войти» по умолчанию скрыта.

Если pointer-oriented profile:
кнопку «Войти» можно включить.

Spacing:
avatar -> username: 10 px.
username -> password: 30 px.
password -> session selector: 10 px, если selector есть.

Power controls:
bottom-left.
Тонкие белые icon buttons.

Фон:
black+stars.

REFERENCE profile может сохранять старую card-композицию для точного воспроизведения исторического изображения.

V3.20. ВИЗУАЛЬНЫЙ ПРИОРИТЕТ
======================================================================

Уровни внимания:

0 — фон.
1 — inactive applications.
2 — active application.
3 — pinned shell.
4 — temporary shell overlays.
5 — notification/urgent event.
6 — authentication/security.

RightPanel в Pinned не должен быть ярче активного IDE.

V3.21. ZEN BROWSER
======================================================================

Тема Zen контролирует:
- browser chrome;
- sidebar;
- tabs;
- URL bar;
- split separators;
- нашу new-tab page.

Она НЕ пытается перекрасить arbitrary websites в системные 4 цвета.

WORK new-tab:
- black+stars;
- compact Zen identity;
- search;
- 4–6 quick actions;
- recent optional;
- без большого пейзажа.

Cosmic landscape — optional preset «Showcase».

Browser outer frame в WORK использует Level A, а не Level C.

======================================================================
V3.23. ФИНАЛЬНЫЙ ОБРАЗ WORK
======================================================================

Нормальный кадр WORK должен выглядеть примерно так по визуальной плотности:

верх:
Arch / рабочие зоны / компактный поиск / состояние / часы

центр:
только рабочие окна

право:
ничего, пока пользователь не вызвал Peek/Pin

низ:
ничего, пока Dock не вызван

Поэтому интерфейс остаётся узнаваемым по материалам, шрифту, фону и движению, а не за счёт постоянного количества виджетов.

======================================================================
V3.25. ПРАВИЛА ПРИЁМКИ V3
======================================================================

WORK FAIL, если:
- RightPanel закреплена при чистом первом запуске.
- Dock постоянно резервирует место при чистом первом запуске.
- Top search занимает старые 474 px в idle.
- CPU/RAM/Network по умолчанию зелёные.
- inactive window border визуально почти такой же яркий, как active.
- обычное tiled окно имеет крупный классический titlebar.
- lock показывает quote по умолчанию.
- login показывает большую центральную glass-card по умолчанию.
- Settings сразу вываливает expert properties в основной экран.
- Design Mode разрешает случайно потерять критические shell controls.
- звёзды заметно двигаются/мерцают в idle.
- system wallpaper является пейзажем.
- Zen theme пытается насильно перекрасить сайты.
- RightPanel Peek вызывает reflow.
- Dock AutoHideOverlay вызывает reflow.
- обычные анимации ощущаются длиннее ~210 ms, кроме camera.

REFERENCE FAIL, если:
- нельзя воспроизвести исторический вид со старой pinned right column, dock, wide search и browser cosmic preset.
